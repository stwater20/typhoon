隱私權政策

最後更新：2026 年 10 月 22 日

颱風假機率計算器（以下稱「本站」，網址 typhoon.sectools.tw）重視你的隱私。本站不需要註冊，也不會要求你提供姓名、電話、Email 等個人資料。以下說明本站會處理哪些資料。

1. 存在你瀏覽器裡的資料

為了記住你的偏好，本站會在你的瀏覽器 localStorage 儲存：選擇的縣市、深淺色主題、最近一次的估算結果，以及你投過的票（用來計算「預言家戰績」）。這些資料只留在你的裝置上，清除瀏覽器資料即可刪除。

2. 網友開票所的投票資料

投票時，本站透過 Google Firebase 的「匿名登入」產生一組隨機識別碼，只用來確保同一個瀏覽器每天只能投一票。伺服器上會儲存：這組匿名識別碼、你投票的縣市、選項（會放假／照常上班）與投票時間。這些資料無法對應到你的真實身分，各縣市票數以匯總方式公開顯示，個別投票紀錄不公開。

3. 定位功能

只有在你主動按下「📍 定位」時，瀏覽器才會詢問定位權限。座標只會傳送給 OpenStreetMap Nominatim 服務換成縣市名稱，本站不會儲存或轉送座標。

4. 第三方服務與 Cookie

  • Google AdSense：本站使用 Google AdSense 顯示廣告。Google 及其合作夥伴可能使用 Cookie，依你先前造訪本站或其他網站的紀錄提供廣告。你可以到 Google 廣告設定 停用個人化廣告，或參考 Google 廣告政策。
  • Google Firebase：提供匿名登入與投票資料庫，見 Firebase 隱私權說明。
  • OpenStreetMap Nominatim：僅在使用定位時呼叫，見 OSMF 隱私權政策。
  • GitHub Buttons：顯示 GitHub 星星數的按鈕。

5. 免責聲明

本站的機率估算與網友投票結果僅供參考娛樂，不代表任何官方立場，也不構成停班停課的保證。是否停止上班上課，請以行政院人事行政總處及各縣市政府正式公告為準。

6. 聯絡我們

對本政策有任何疑問，歡迎到 GitHub Issues 留言。
